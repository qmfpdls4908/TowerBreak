# 타워 브레이커 스토리보드

## 개요

- 문서 목적: `타워 브레이커`의 화면/UX 중심 플레이 흐름을 한눈에 보여주는 스토리보드 정리
- 기준 기획: `docs/plans/기획서.docx`
- 핵심 루프: `전투 -> 보상 -> 성장 -> 재도전`
- 표현 범위: `타이틀 -> 로비 -> 전투 진입 -> 기본 전투 -> 위기 극복 -> 클리어 보상 -> 성장 -> 다음 층 도전`

## 스토리보드 전체 흐름

### 컷 1. 타이틀 화면

- 화면 목적: 세계관과 최종 목표를 짧고 강하게 전달
- 화면 구성:
  - 배경에 거대한 검은 탑과 붉은 하늘
  - 전경에 플레이어 캐릭터 실루엣 배치
  - 중앙에 `Tower Breaker` 로고 노출
  - 서브 카피 `111층의 마의 탑을 돌파하라`
  - 버튼 `게임 시작`, `이어하기`, `설정`
- 사용자 인지 포인트:
  - 다크 판타지 픽셀 액션 게임이라는 인상 형성
  - 목표가 `탑 등반`이라는 점을 즉시 이해

### 컷 2. 메인 로비

- 화면 목적: 전투 진입 전 준비와 성장 허브 역할 전달
- 화면 구성:
  - 중앙에 현재 장비를 착용한 플레이어 캐릭터 표시
  - 상단에 `전투력`, `골드`, `재화` 배치
  - 우측에 `현재 도전 층수`와 추천 목표 표시
  - 하단 메뉴에 `장비`, `강화`, `리롤`, `탑 도전`
- 사용자 인지 포인트:
  - 여기가 준비와 선택의 중심 화면임을 이해
  - 가장 강한 시선 유도는 `탑 도전` 버튼으로 집중

### 컷 3. 전투 진입 연출

- 화면 목적: 로비에서 전투로 자연스럽게 넘어가는 흐름 제공
- 화면 구성:
  - 선택한 층 정보와 적 경고 문구 노출
  - 필드가 횡스크롤 전투 화면으로 전환
  - 좌측에 플레이어, 우측에 적 무리 등장
  - 짧은 튜토리얼 오버레이로 `대시`, `방어`, `공격` 설명
- 사용자 인지 포인트:
  - 조작이 단순한 3버튼 기반이라는 점 학습
  - 전투의 시작 조건과 긴장감 형성

### 컷 4. 기본 전투 화면

- 화면 목적: 게임의 핵심인 `라인 밀기 전투`를 보여줌
- 화면 구성:
  - 좌측 상단에 하트 HP 표시
  - 상단 중앙에 `층수`, `웨이브`, 진행 상태 표시
  - 하단에 `대시`, `방어`, `공격` 버튼 고정 배치
  - 플레이어는 공격 유지, 적은 좌측으로 압박
- 사용자 인지 포인트:
  - 일반 전투가 아니라 줄다리기형 공방전이라는 점 이해
  - 버튼 입력과 전투 거리 조절이 핵심임을 체감

### 컷 5. 위기 상황 / 벽 충돌 직전

- 화면 목적: 긴장감과 실패 조건을 명확히 전달
- 화면 구성:
  - 적 무리가 한 번에 밀고 들어와 플레이어가 좌측 끝으로 후퇴
  - 하트 하나가 붉게 점멸
  - 경고 문구 `위기! 밀려나면 HP 감소`
  - 공격 버튼은 약하게 보이고 `대시`, `방어`가 강조됨
- 사용자 인지 포인트:
  - 벽까지 밀리면 패널티가 발생한다는 규칙 인지
  - 위기 상황에서 순간 대응이 중요하다는 점 학습

### 컷 6. 반격 / 라인 회복

- 화면 목적: 수세에서 공세로 전환되는 손맛 강조
- 화면 구성:
  - 플레이어가 `방어`로 라인을 밀어냄
  - 곧바로 `대시`로 적과의 거리를 좁힘
  - 다시 `공격`을 이어가며 전선을 회복
  - 보조 UI로 `살기 게이지 상승` 또는 `악마화 게이지 축적` 노출 가능
- 사용자 인지 포인트:
  - 위기 이후에도 역전이 가능한 구조라는 점 이해
  - 단순 스펙 게임이 아니라 조작 타이밍이 중요하다는 점 체감

### 컷 7. 전투 클리어 / 보상 획득

- 화면 목적: 플레이 결과가 성장 자원으로 환원되는 구조 전달
- 화면 구성:
  - `층 클리어` 배너 노출
  - 보상 카드 형태로 `골드`, `장비`, `상자`, `강화 재료` 표시
  - 10층 단위에서는 `체크포인트 저장 완료` 메시지 추가
- 사용자 인지 포인트:
  - 전투의 보상이 즉시 제공된다는 점에서 만족감 형성
  - 체크포인트를 통해 재도전 부담이 줄어든다는 점 이해

### 컷 8. 성장 화면 / 다음 층 도전 준비

- 화면 목적: 전투 후 성장과 다음 목표 설정까지 연결
- 화면 구성:
  - 인벤토리에서 새 장비 확인
  - 무기 타입 `클로`, `창` 비교 가능
  - 액션 버튼 `강화`, `분해`, `리롤`
  - 우측 패널에 `다음 목표: 11층 돌파` 같은 진행 목표 표시
- 사용자 인지 포인트:
  - 장비 선택과 육성 판단이 핵심 재미라는 점 이해
  - 성장 후 바로 다음 도전으로 이어지는 동기 형성

## 연출 포인트 요약

- 전반 톤: 레트로 픽셀 아트 + 다크 판타지
- 핵심 감정 흐름: `도전 -> 압박 -> 위기 -> 반격 -> 보상 -> 성장 -> 재도전`
- 가장 중요한 차별화 포인트:
  - `3버튼 기반의 직관적 조작`
  - `적과의 라인 밀기 공방`
  - `장비 파밍과 리롤 기반 성장`
  - `111층 탑 체크포인트 구조`

## 발표용 한 줄 요약

`타워 브레이커`의 스토리보드는 짧은 조작 학습만으로도 전투의 긴장감, 보상의 쾌감, 성장의 동기를 반복 경험하게 만드는 화면 흐름에 초점을 둔다.
